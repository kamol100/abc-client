1. Open **Help**, then **Chat with support**. You can also open **Platform Support** and choose **Chats**.
2. If you already have an open chat, that chat opens again. A new message is not sent for you. The screen can say that the chat was already open and the message was not sent yet.
3. Write a **Message** of at most 10,000 characters, or attach an image, then select **Send**. Wait until each image is **Ready** before sending.
4. **Close chat** is shown only when this chat allows it. After a chat is closed, sending stays unavailable until it can be reopened.

**New messages** appears when more messages arrive while you are not at the bottom of the conversation. **Load older messages** loads earlier messages.
