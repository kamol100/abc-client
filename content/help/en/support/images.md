On an issue or chat you can reply to, **Add images** accepts JPEG, PNG, or WebP. You can attach up to 5 images, and each file must be 5 MB or smaller.

1. Select **Add images** and choose the files.
2. Wait until each image shows **Ready**. Sending stays blocked while an image is still uploading.
3. A message needs text or at least one image.
4. **Remove image** drops a file before you send. If an upload fails, use **Retry upload**.

People who can open that request can see the images you send. Do not attach passwords, tokens, or identity documents.
