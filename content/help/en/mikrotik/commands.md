Open **MikroTik commands**. Choose a network and one command, then run it. The only commands in the form are /ip/address/print, /ppp/profile/print, /ppp/active/print, and /ppp/secret/print. They are print commands. /ppp/secret/print can return PPP secrets. Do not copy secrets into support. This page does not document reboot, disable, or any command outside that list. Do not run a command on a live router to produce this guide.
