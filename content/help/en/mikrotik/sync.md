Open **MikroTik sync**. **Import** loads data from MikroTik into this app. **All Sync** syncs client package and status between MikroTik and this app. A bulk action can import as Own or Reseller, and Reseller requires a reseller. These actions change records. The older Import client and Re-sync items are commented out of the menu. Do not start a sync to test this article.
